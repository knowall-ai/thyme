= Thyme Solution Design
:toc:
:toclevels: 3

== Overview

Thyme is a modern time tracking web application designed for KnowAll.ai team members. It integrates with Microsoft Dynamics 365 Business Central for project/job data synchronization and uses Microsoft Entra ID for authentication.

=== URL Structure

Every company-scoped page carries the Business Central environment and company in its URL, mirroring BC's own `/{tenant}/{environment}/...` shape, so links can be shared and bookmarked:

[source]
----
/{environment}/{companyId}/{page}

/production/00000000-0000-0000-0000-000000000001/projects/PR00100
/sandbox/00000000-0000-0000-0000-000000000002/plan
----

* `{environment}` is the environment Thyme stores on the company (`production` or `sandbox`, matched case-insensitively) and `{companyId}` is the BC company GUID. Company identity is id + environment, because a sandbox copy can share GUIDs with Production.
* Company pages (Time, Projects, Team, Plan, Approvals, Reports, Settings) live under `src/app/[environment]/[companyId]/`. Its layout 404s anything that isn't a known environment plus a GUID, then `CompanyRouteGate` makes the URL's company the active one before rendering the page. If the user doesn't have that company, it shows "You don't have access to that company in Business Central" instead of another company's data.
* Public pages (`/`, `/pricing`, `/help`, `/privacy`, `/terms`, `/eula`) stay at the top level.
* The old unprefixed URLs (`/time`, `/projects/PR00100`, ...) live in `src/app/(legacy)/` and redirect to the same page under the remembered company, keeping the query string and hash.
* Build internal links with `useCompanyPath()` (e.g. `toHref('/projects')`) rather than hard-coding paths. Switching company in the picker opens the same page under the new company; detail pages such as `/projects/PR00100` fall back to their list page.
* Signed-out visitors to a company URL see the landing page in place. MSAL's `navigateToLoginRequestUrl` returns them to the URL they opened once they've signed in.

=== State Management

The application uses Zustand for state management with the following stores:

* **useTimerStore** - Timer state with persistence (localStorage)
* **useProjectsStore** - Projects and tasks from Business Central
* **useTimeEntriesStore** - Time entries with local caching
* **useSettingsStore** - User preferences with persistence

== Data Flow

=== Authentication Flow

[source]
----
1. User clicks "Sign in with Microsoft"
2. MSAL.js initiates OAuth 2.0 authorization code flow
3. User authenticates with Microsoft Entra ID
4. Token returned with BC API scope
5. Token stored in browser (managed by MSAL)
6. App renders authenticated dashboard
----

=== Time Entry Flow

[source]
----
1. User creates/edits time entry in UI
2. Entry saved to local state (immediate feedback)
3. Entry queued for sync with BC
4. Background sync creates Job Journal Line in BC
5. Sync status updated (pending → synced)
----

=== API Endpoints

[source]
----
GET  /companies({id})/jobs                    # Fetch all projects
GET  /companies({id})/jobs({id})/jobTaskLines # Fetch tasks for project
GET  /companies({id})/resources               # Fetch employees
POST /companies({id})/jobJournalLines         # Create time entry
----

=== Linked sources (Poppie's project mapping)

Poppie, the AI agent, suggests time entries from people's calendars, GitHub and Azure DevOps.
Which project that time belongs to comes from each project's *linked sources* in Business
Central (Thyme BC Extension 1.20+ `projectSourceLinks`): GitHub repos, DevOps projects and
repos, meeting keywords and attendee domains, each optionally with a task. They're per company,
so every company maps its own projects.

* The project page's *Linked sources* card lists them, with link-outs for repos and DevOps
  projects. Administrators and the project's manager (`canEditSourceLinks` on `projects`) add,
  edit and remove them inline; values are checked and normalised as BC will store them
  (`src/utils/projectSourceLinks.ts`), and BC re-checks.
* Adding a "Choose project" suggestion offers *Always map this to the chosen project and task*,
  which creates the link (repo, DevOps repo or project, meeting subject or attendee domain).
* Links Poppie learns from approved time appear as *Learned*.

== Security Considerations

=== Authentication

* Microsoft Entra ID provides enterprise-grade authentication
* Single Sign-On (SSO) for KnowAll.ai users
* Token refresh handled automatically by MSAL.js
* No passwords stored in application

=== Authorization

* Only authenticated KnowAll.ai users can access
* BC API access controlled by token scope
* User can only see/edit own time entries (enforced in UI)

=== Data Protection

* All communication over HTTPS
* Tokens stored securely (MSAL manages)
* Local cache encrypted in localStorage
* No sensitive data in URL parameters
